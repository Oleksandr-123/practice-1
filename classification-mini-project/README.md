# Порівняння класичних моделей класифікації

## Опис проєкту

Проєкт присвячений порівнянню класичних моделей машинного навчання для задачі бінарної класифікації на наборі даних Heart Disease.

Мета роботи — підготувати дані, навчити різні моделі класифікації, порівняти їхні результати та обрати найкращу модель.

## Структура проєкту

- `data/` — набір даних heart.csv.
- `notebooks/` — практичні роботи № 4–7.
- `models/` — збережена фінальна модель.
- `reports/` — таблиці з результатами оцінювання.

## Набір даних

Використано набір даних Heart Disease:
- 303 записи;
- 13 вхідних ознак;
- цільова змінна `target`;
- клас 0 — відсутність захворювання;
- клас 1 — наявність захворювання.

## Виконані практичні роботи

**Практична робота № 4**
- Підготовка та аналіз даних.
- Розподіл на навчальну та тестову вибірки.
- Створення Pipeline.
- Навчання Logistic Regression.

**Практична робота № 5**
- Дослідження моделі k-NN.
- Порівняння моделей GaussianNB, LDA та QDA.
- Дослідження впливу масштабування ознак.
- Порівняння результатів моделей.

**Практична робота № 6**
- Дослідження лінійної та RBF-моделей SVM.
- Підбір гіперпараметрів.
- Використання GridSearchCV.

**Практична робота № 7**
- Побудова ROC-кривих.
- Порівняння моделей за результатами крос-валідації.
- Побудова матриць помилок.
- Вибір та остаточне оцінювання фінальної моделі.
- Аналіз помилкових прогнозів.
- Збереження та перевірка моделі.

## Методологія

Для оцінювання використовувалася п'ятикратна стратифікована крос-валідація (StratifiedKFold).

Дані розділено на навчальну та тестову вибірки у співвідношенні 80/20.

Попередня обробка даних виконувалася за допомогою Pipeline та ColumnTransformer.

Для порівняння моделей використовувалися Accuracy, Precision, Recall, F1-score та ROC AUC.

## Результати крос-валідації

| Модель | CV F1 | CV Recall | CV ROC AUC |
|---|---:|---:|---:|
| k-NN | 0.8528 | 0.8635 | 0.8861 |
| LDA | 0.8527 | 0.8781 | 0.8900 |
| SVM | 0.8491 | 0.8937 | 0.8900 |
| Logistic Regression | 0.8437 | 0.8786 | 0.8684 |
| QDA | 0.8432 | 0.8558 | 0.8804 |
| GaussianNB | 0.7318 | 0.6368 | 0.8608 |

## Фінальна модель

Для остаточного оцінювання обрано Linear Discriminant Analysis (LDA).

Результати на тестовій вибірці:

| Метрика | Результат |
|---|---:|
| Accuracy | 0.8361 |
| Precision | 0.7949 |
| Recall | 0.9394 |
| F1-score | 0.8611 |
| ROC AUC | 0.9134 |

Модель правильно класифікувала більшість об'єктів тестової вибірки.
